\# Q1 - Dijkstra Algorithm on Indian Road Network



\## Aim



To implement Dijkstra's Algorithm to find the minimum-cost route between cities in a representative Indian road network.



\## Algorithm



Dijkstra's Algorithm / Uniform Cost Search (UCS)



\## Working



The program uses a priority queue to explore cities based on the lowest accumulated road distance.



\## Input



\- Source city

\- Destination city



\## Output



\- Shortest route

\- Total road distance

\- Cities explored



\## File



`q1\_dijkstra\_india.py`



\## Conclusion



Dijkstra's Algorithm successfully finds the minimum-cost route between the selected cities.
