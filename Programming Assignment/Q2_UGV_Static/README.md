\# Q2 - UGV Static Obstacle Navigation



\## Aim



To implement A\* Search for autonomous UGV navigation in a grid containing known static obstacles.



\## Algorithm



A\* Search



\## Grid Size



70 × 70



\## Heuristic



Manhattan Distance



`h(n) = |x1 - x2| + |y1 - y2|`



\## Obstacle Densities



\- 10%

\- 25%

\- 40%



\## Measurements



\- Path length

\- Cells explored

\- Execution time

\- Mission status



\## Files



\- `q2\_ugv\_static.py`

\- `q2\_ugv\_visual.py`



\## Conclusion



A\* successfully navigates the UGV through static obstacles while avoiding blocked cells.
