\# Artificial Intelligence Assignment



\## Search Techniques and UGV Path Planning



This assignment demonstrates Artificial Intelligence search techniques and their application in route finding and autonomous UGV navigation.



\## Topics Covered



\### Uninformed Search

\- Breadth First Search (BFS)

\- Uniform Cost Search (UCS)

\- Depth First Search (DFS)

\- Depth Limited Search (DLS)

\- Iterative Deepening Search (IDS)

\- Bidirectional Search



\### Informed Search

\- Greedy Best First Search

\- Best First Search

\- Dijkstra's Algorithm

\- A\* Search

\- Beam Search

\- RBFS

\- IDA\*

\- Weighted A\*



\### Heuristics

\- Satisficing Search

\- Admissible Heuristics

\- Heuristic Formulation

\- Heuristics from Subproblems



\## Practical Implementations



\### Q1 - Dijkstra / Uniform Cost Search



Dijkstra's algorithm is implemented on a representative Indian city road network to find minimum-cost routes between cities.



\### Q2 - UGV Static Obstacle Navigation



A\* search is used to navigate a UGV through a 70 × 70 grid containing static obstacles.



Obstacle densities tested:

\- 10%

\- 25%

\- 40%



\### Q3 - UGV Dynamic Obstacle Navigation



A\* with dynamic replanning is used to navigate a UGV in a changing environment.



The system detects new obstacles and replans the path when required.



Grid size: 30 × 30
