# Indian Route Search

A basic AI mini project using Uniform Cost Search to find a minimum-cost route between major Indian cities.

- Cities are nodes.
- Roads are edges.
- Road distance is the cost.
- Uniform Cost Search finds the route with minimum total cost.

Run:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000

The distances are approximate values used only for demonstrating the AI search algorithm.
